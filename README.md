# Zarautz Surf Festival

Aquest projecte consisteix en una pagina web desenvolupada durant el curs anterior, en la qual s'apliquen els coneixements adquirits en desenvolupament web. La web esta dissenyada per oferir una navegacio senzilla i una presentacio clara dels seus continguts.

## Tecnologies

Per desenvolupar aquest projecte he utilitzat les seguents tecnologies: HTML5 per crear l'estructura i el contingut de la pagina, CSS3 per poder dissenyar l'aparenca visual i l'estil de la pagina, JavaScript per afegir funcionalitats i interactivitat, si escau


## Com obrir-la en local

Per visualitzar la pagina web s'han de seguir els seguents passos:

1. Descarrega o clona aquest repositori de GitHub.
2. Desar tots els fitxers del projecte a la mateixa carpeta, mantenint l'estructura original.
3. Obre el fitxer index.html amb un navegador web, com ara Google Chrome o Safari.

## Web publicada

La pagina web es publicara mitjancant Firebase Hosting perque es pugui consultar a travvs d'una URL publica.
Enllac a la web publicada: https://web-curs-anterior-2989a.web.app
